RIVIERA JOURNEYS — FAVICON (brand-built)
========================================
The "RJ" monogram — Cormorant SC, weight 300, Warm Black #1C1C1A on Warm White #FDFAF6 —
rebuilt as true vector outlines (from the brand font) and rendered to every icon size.
No embedded @font-face (that was why the old SVG favicon showed blank in tabs).

Files in this zip (extract at repo ROOT — overwrites):
  favicon.svg                 self-contained vector, crisp at any size (retina tabs use this)
  favicon.ico                 multi-size 16/32/48
  favicon-16x16.png
  favicon-32x32.png
  apple-touch-icon.png        180x180 (iOS home screen)
  android-chrome-192x192.png
  android-chrome-512x512.png
  site.webmanifest            name + brand colours + Android icons
  79x index.html              identical 6-line favicon block in <head>

Apply:
  1. Extract zip at repo root.
  2. git rm add-favicon.yml        (redundant workflow — would re-diverge the pages)
  3. git add -A && git commit -m "favicon: brand RJ monogram, vector + full icon set + manifest" && git push
  Auto-deploy 15-30s. Favicons cache hard: after deploy hard-refresh (Cmd+Shift+R) or open /favicon.ico once.

Head block now on every page:
  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
  <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  <link rel="manifest" href="/site.webmanifest">
